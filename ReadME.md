# Генератор тестового сигнала

Программа для генерации и воспроизведения тестовых звуковых сигналов (синусы,
свипы, шум) или проигрывания WAV-файлов с одновременным приёмом UDP-пакетов
и сохранением их в `.bin` и `.wav`.

## Возможности

- Генерация сигнала по шаблону из `config.json` или воспроизведение готового WAV-файла
- Структура сигнала: импульс СТАРТ → группа синусов → группа свипов → группа шума → импульс СТОП
- Все блоки настраиваются отдельно (частоты, длительности, паузы, уровни)
- Приём UDP-пакетов с фильтрацией по IP источника и порту
- Сохранение принятых данных в `.bin` (сырые пакеты) и `.wav` (4-канальный звук)
- Индикатор связи с источником (ping) — зелёный / красный / серый кружок
- Проверка связи по клику на индикатор или автоматически раз в минуту
- Логирование параметров запуска и расписания воспроизведения
- Сборка в один `.exe` файл через PyInstaller

## Требования

- Python 3.7+
- Библиотеки: `numpy`, `sounddevice`

```bash
pip install numpy sounddevice
```

## Запуск

```bash
python signal_generator.py
```

При первом запуске рядом со скриптом автоматически создаётся файл `config.json`
с настройками по умолчанию. При желании его можно отредактировать любым
текстовым редактором и нажать кнопку «Перечитать» в интерфейсе.

---

## Структура файлов

При каждом запуске (нажатии «СТАРТ») создаётся папка с результатами:

```
signal_generator.py
config.json                          # создаётся автоматически при первом запуске
Angle_0/                             # папка результатов (Angle_<угол>)
 ├── Лог_2026-01-01_12-00-00.txt     # лог запуска: начало, параметры,
 │                                   # расписание сегментов с временами,
 │                                   # статистика приёма UDP, конец
 ├── Исходник.wav                    # сгенерированный сигнал
 │                                   # (только в режиме «Генерация»)
 ├── data_2026-01-01_12-00-00.bin    # сырые UDP-пакеты
 └── data_2026-01-01_12-00-00.wav    # данные UDP в формате 4-канального звука
```

Для отрицательных углов папка называется `Angle_-15` (знак минуса в имени
файла допустим во всех операционных системах).

## Формат данных UDP

| Параметр | Значение |
|---|---|
| Размер пакета | 1293 байт |
| Заголовок | 13 байт (отрезается при `strip_header: true`) |
| Полезные данные | 1280 байт = 640 семплов `int16` |
| Каналов | 4 |
| Семплов на канал | 160 (640 / 4) |
| Частота дискретизации | 46875 Гц |
| Длительность одного пакета | 13.65 мс |
| Раскладка каналов в пакете | `[канал 1 (160)] [канал 2 (160)] [канал 3 (160)] [канал 4 (160)]` |

### Файл `.bin`

Сырые байты UDP-пакетов, записанные подряд без разделителей.
При `strip_header: true` — по 1280 байт на пакет (без заголовка).
При `strip_header: false` — по 1293 байта на пакет (с заголовком).

### Файл `.wav`

4-канальный звуковой файл, создаваемый автоматически после остановки приёма.
Семплы расположены в interleaved-формате:
`[ch1_s0, ch2_s0, ch3_s0, ch4_s0, ch1_s1, ch2_s1, ...]`

## Файл настроек `config.json`

```json
{
    "sample_rate": 46875,
    "start_silence_s": 1.0,
    "end_silence_s": 1.0,
    "general_pause_s": 2.0,
    "impulse": {
        "duration_ms": 5,
        "level_percent": 100
    },
    "sine": {
        "freq_start_hz": 100,
        "freq_end_hz": 2000,
        "freq_step_hz": 100,
        "duration_s": 2.0,
        "pause_s": 1.0,
        "levels_percent": [25, 50, 75, 100]
    },
    "sweep": {
        "freq_start_hz": 100,
        "freq_end_hz": 2000,
        "round_trip": true,
        "duration_s": 10.0,
        "pause_s": 1.0,
        "levels_percent": [25, 50, 75, 100]
    },
    "noise": {
        "type": "pink",
        "duration_s": 10.0,
        "pause_s": 1.0,
        "levels_percent": [25, 50, 75, 100],
        "seed": 12345
    },
    "udp_receiver": {
        "enabled": true,
        "local_port": 45920,
        "source_ip": "192.168.0.9",
        "packet_size": 1293,
        "header_size": 13,
        "filename": "data.bin",
        "strip_header": true
    }
}
```

### Описание параметров

| Раздел | Параметр | Описание |
|---|---|---|
| корень | `sample_rate` | частота дискретизации, Гц |
| корень | `start_silence_s` | тишина перед импульсом СТАРТ, с |
| корень | `end_silence_s` | тишина после импульса СТОП, с |
| корень | `general_pause_s` | общие паузы между группами, с |
| `impulse` | `duration_ms` | длительность импульсов СТАРТ/СТОП, мс |
| `impulse` | `level_percent` | уровень импульса, % |
| `sine` | `freq_start_hz` / `freq_end_hz` / `freq_step_hz` | диапазон частот синусов |
| `sine` | `duration_s` | длительность одного тона (0 = отключить группу) |
| `sine` | `pause_s` | пауза между тонами, с |
| `sine` | `levels_percent` | список уровней, % |
| `sweep` | `round_trip` | `true` = туда-обратно, `false` = только туда |
| `sweep` | остальные | аналогично `sine` |
| `noise` | `type` | `"white"` / `"белый"` или `"pink"` / `"розовый"` |
| `noise` | `seed` | зерно ГПСЧ (одинаковый шум при перезапусках) |
| `udp_receiver` | `enabled` | включить приём при старте |
| `udp_receiver` | `local_port` | локальный порт для прослушивания |
| `udp_receiver` | `source_ip` | IP источника (пустая строка = любой) |
| `udp_receiver` | `packet_size` | ожидаемый размер пакета, байт |
| `udp_receiver` | `header_size` | размер заголовка в пакете |
| `udp_receiver` | `filename` | базовое имя файла (к нему добавится временная метка) |
| `udp_receiver` | `strip_header` | `true` = писать только данные без заголовка |

Индикатор связи (кружок рядом с полем IP):

- **Зелёный** — источник доступен (ping есть)
- **Красный** — источник недоступен
- **Серый** — неизвестно / идёт проверка

Проверка запускается по клику на кружок, автоматически раз в минуту,
а также при выходе из поля IP.

## Нюансы реализации

- **«Мощность» (уровень) трактуется как доля амплитуды**:
  25 % означает амплитуду 0.25 от полной шкалы (32767).
- **Свип сделан с непрерывной фазой** (интеграл частоты), без скачка фазы
  на границе «туда → обратно».
- **Уровень шума задаётся по пиковому значению**, чтобы гарантированно
  не было клиппинга. RMS белого шума при этом примерно в 4-5 раз ниже пика.
- **Розовый шум** генерируется FFT-методом (спектральная плотность ~ 1/f).
- **Зерно ГПСЧ** (`noise.seed`) фиксировано — одна и та же реализация шума
  при каждом запуске.
- **Для отрицательных углов** папка называется `Angle_-15` (знак минуса
  в имени допустим).
- **При `strip_header: true`** в `.bin` пишутся только данные (1280 байт
  на пакет). При `false` — весь пакет целиком (1293 байт).
- **WAV-файл создаётся после остановки** приёмника, а не во время записи.
  Это надёжнее: при сбое не теряется частично записанный WAV.

## Сборка в .exe (PyInstaller)

### Шаг 1. Установите PyInstaller

```bash
pip install pyinstaller
```

### Шаг 2. Соберите .exe одной командой

**Windows (cmd):**

```bat
pyinstaller --noconfirm --onefile --windowed ^
    --name "SignalGenerator" ^
    --collect-all sounddevice ^
    --collect-all numpy ^
    --icon "sound.ico" ^
    signal_generator.py
```

**Linux / macOS / PowerShell (одной строкой):**

```bash
pyinstaller --noconfirm --onefile --windowed \
    --name "SignalGenerator" \
    --collect-all sounddevice \
    --collect-all numpy \
    --icon "sound.ico" \
    signal_generator.py
```

| Флаг | Назначение |
|---|---|
| `--onefile` | всё в одном `.exe` (распаковывается во временную папку при запуске) |
| `--windowed` | без консольного окна (GUI-приложение) |
| `--name` | имя выходного `.exe` |
| `--collect-all sounddevice` | подхватывает PortAudio DLL и все ресурсы `sounddevice` |
| `--collect-all numpy` | гарантирует, что все модули `numpy` попадут в сборку |
| `--icon` | путь к `.ico` файлу для значка (необязательно) |

### Шаг 3. Где взять результат

После сборки:

```
signal_generator.py
build/                     ← временная папка (можно удалить)
dist/
  SignalGenerator.exe      ← готовый файл
```

### Шаг 4. Как это работает при запуске .exe

1. PyInstaller распаковывает внутренности во временную папку (`sys._MEIPASS`)
2. Код определяет, что он заморожен (`sys.frozen == True`)
3. В качестве рабочей папки (`_base_dir`) берётся **папка рядом с .exe**:
   `os.path.dirname(sys.executable)`
4. В этой папке создаётся `config.json` (при первом запуске)
5. При нажатии «СТАРТ» там же создаются папки `Angle_<N>` с логами,
   `Исходник.wav`, `data_*.bin`, `data_*.wav`

```
C:\Tools\SignalGenerator.exe        ← запускаете это
C:\Tools\config.json                ← создаётся автоматически
C:\Tools\Angle_0\                   ← создаётся при первом СТАРТ
         Лог_2026-01-01_12-00-00.txt
         Исходник.wav
         data_2026-01-01_12-00-00.bin
         data_2026-01-01_12-00-00.wav
```

### Возможные проблемы

| Проблема | Решение |
|---|---|
| `ModuleNotFoundError: sounddevice` в .exe | добавьте `--collect-all sounddevice` |
| .exe не запускается, ошибка PortAudio | добавьте `--hidden-import sounddevice._sounddevice` |
| Антивирус ругается на .exe | особенность `--onefile`; используйте `--onedir` вместо `--onefile` |
| Размер .exe большой (~50 МБ) | нормально для Python + NumPy + sounddevice |
| Ping не работает | проверьте брандмауэр (не блокирует ли `ping.exe`) |

## Чтение записанных данных

### Чтение `.bin` и разбивка на 4 канала

```python
import numpy as np

STRIP_HEADER = True
HEADER_SIZE  = 13
CHANNEL_SIZE = 160
N_CHANNELS   = 4
SAMPLE_RATE  = 46875

raw = np.fromfile("data.bin", dtype=np.uint8)
bytes_per_packet = (N_CHANNELS * CHANNEL_SIZE * 2) if STRIP_HEADER \
    else (HEADER_SIZE + N_CHANNELS * CHANNEL_SIZE * 2)

n_packets = len(raw) // bytes_per_packet
raw = raw[:n_packets * bytes_per_packet]
packets = raw.reshape(n_packets, bytes_per_packet)

if not STRIP_HEADER:
    packets = packets[:, HEADER_SIZE:]

samples = packets.view(np.int16)   # (n_packets, 640)

channels = []
for ch in range(N_CHANNELS):
    channels.append(
        samples[:, ch * CHANNEL_SIZE:(ch + 1) * CHANNEL_SIZE].reshape(-1))

matrix = np.stack(channels, axis=1)   # (N_total, 4)
print(f"Пакетов: {n_packets}, форма: {matrix.shape}")
```

### Чтение `.wav` (4-канальный)

```python
import wave, numpy as np

with wave.open("data.wav", "rb") as wf:
    n_ch = wf.getnchannels()
    fs   = wf.getframerate()
    raw  = wf.readframes(wf.getnframes())

data = np.frombuffer(raw, dtype=np.int16).reshape(-1, n_ch)
print(f"Каналов: {n_ch}, частота: {fs}, форма: {data.shape}")
```
