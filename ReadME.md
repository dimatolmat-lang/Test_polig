Куда вставлять ваши функции (п.5):

user_hook_on_start() — вызывается при нажатии «СТАРТ» (после создания папки, до начала звука). Если нужно непосредственно перед звуком — перенесите вызов в _worker_run, место отмечено комментарием.
user_hook_on_stop(reason) — вызывается при остановке вручную, после окончания или при ошибке (в reason приходит "manual" / "finished" / "error").
Что создаётся при запуске (пп. 6–8):

text

Угол_15/
 ├── Лог_2025-01-15_12-00-00.txt   # начало, описание (для WAV — имя и путь,
 │                                 #  для генерации — всё расписание с временами),
 │                                 #  конец
 └── Исходник.wav                  # только в режиме «Генерация»
Нюансы:

Полная генерация — ~64 мин, «Исходник.wav» — ~320 МБ. Хотите вдвое меньше — поставьте SAMPLE_RATE = 22050 (максимум 2 кГц это позволяет).
«Мощность» трактуется как доля амплитуды (25 % → амплитуда 0.25). Если нужен физический смысл мощности — см. комментарий у POWER_LEVELS.
Свип сделан с непрерывной фазой (интеграл частоты), без «скачка» на 2 кГц.
Для отрицательных углов папка будет называться Угол_-15 (это допустимое имя).
Если что-то нужно поправить (порядок в логе, цвета, поведение кнопки) — скажи, подгоню.
